PIMPOM ソフトウェア仕様書

対象: PIMPOM2022.sln（Visual Studio 2022 / x64）。ソースコードの解析結果を主とし、Doc フォルダの既存資料（ソフトウェア仕様書 pptx、API リファレンス、スクリプト・PimpomPy・外部プログラム受け渡しの各マニュアル）で補った。

目的

PIMPOM（Platform for Image Processing Observer & Modifier）は、画像処理アルゴリズム開発の「技術検討」段階を効率化するためのラピッドプロトタイピングツールである。技術検討は次の 3 つの作業の繰り返しであり、PIMPOM はこのループを確実かつ素早く回すことを狙う。

作業内容PIMPOM が提供するもの
現象解析内部で何が起きているかを正確に知るヒストグラム・ルーラー・チャートによる可視化、16bit／動画／複素数など多様なデータ型、外部プログラムからの画像転送・表示、フリーハンド編集、数式による画像生成
実装・改善現象に合ったアルゴリズムを実装するカスタムファンクション（ユーザー DLL）の雛形生成と API による全機能の利用、Python からの利用、内蔵フィルタ・幾何変換、OpenCV 4.4 同梱
効果検証対策の効果を多数のデータで確かめるバッチ実行（複数画像ファイルへの一斉実行）、スクリプト、Python バッチ

主な機能

画像メモリ

既定 100 面（pimpom.ini で変更可、上限 1000）の画像メモリに 13 種類のデータ型（BYTE〜DWORD）を保持。マスク・作業領域・マークを画像ごとに持つ。

表示と観察

拡大縮小・スクロール・表示濃度レンジ・カラーパレット、画素値表示、ルーラー、濃度プロファイル。

解析ウィンドウ

データ一覧、ヒストグラム、マーク、作業領域、チャート、複数画像同時表示、3D 点群表示。

画像処理

汎用フィルタ、2 値化とラベリング、型変換、サイズ変換、幾何変換、数式による画像生成。

スクリプト

独自スクリプト言語（数式＋マクロ関数）とスクリプトウィンドウ、バッチ実行との連動。

外部連携と拡張

カスタムファンクション DLL、Python（PimpomPy）、外部 C++ プログラムからの画像転送、TCP/IP 通信、ビデオキャプチャ。

用語の定義

用語定義
PIMPOM本ソフトウェアの名称。Platform for Image Processing Observer & Modifier の略。
画像メモリPIMPOM 内部で画像を保持する領域（CDataUnit）。複数持てる（既定 100、上限 1000）。0 始まりの番号で指定する。
バックアップメモリ上書き・削除・処理の直前の画像データを退避する領域。全画像メモリで共通の 1 面だけで、「画像データ復元」で戻せる（Undo 1 段）。
作業領域処理・統計の対象範囲を表す図形（矩形／直線／楕円／円周）の集合。OR／NOT 指定可能。
マスク画素単位で処理・統計の対象外を表す 8bit 配列。表示では黒く塗られる。
マーク特定画素の座標（サブピクセル）と属性を保持する点・線のデータ。
カスタムファンクションユーザーが機能を追加実装するモードレスダイアログを持つ DLL。雛形のソリューションを生成できる。
APICPimpomAPI クラス。PIMPOM の全機能を提供し、カスタムファンクションから使用できる。
PimpomPyPython から PIMPOM を操作するための拡張モジュール（Pimpom.pyd）。

設計方針

項目方針
性能本体搭載の処理は「精度 ＞ 速度」の優先順位で開発する。SSE など特定ハードに依存する処理は使わない。速度・精度とも保証はない。
品質動作保証はない。機能追加時は正常系の動作確認までを行う。
バージョン1 桁目: 全面的な構成変更 ／ 2 桁目: メニュー・ウィンドウ追加 ／ 3 桁目: 小規模な機能追加

7. スクリプト

PIMPOM は独自の行指向スクリプト言語を持つ。数式ウィンドウ（画素ごとの式）とスクリプトウィンドウ（手続き的な処理）で同じ評価器 CCalculate（DataWrapper/Calculate.cpp、CalculateMacro.cpp）を使う。

概要

項目仕様
実行単位1 行 1 文。各行は 1 つの結果（数値または文字列）を持ち、Res(行番号) で参照できる（行番号は 0 始まり）
型数値（double）と文字列（最大 1023 バイト）の 2 種。動的型付けで、代入で型が決まる
変数var a, b, c で宣言。全行で共有するグローバル変数（最大 150 個）
制御構文if / elseif / else / endif、while / endwhile、for / endfor、goto(n)、break、clear
関数マクロ関数 163 種（オーバーロード込み 186 定義）。名前は大文字小文字を区別する
コメント// から行末まで
実行環境数式ウィンドウ（全画素に式を適用）、スクリプトウィンドウ（1 行ずつ実行）、バッチ実行、外部プログラムの ExecuteCommand、Python（Pimpom.pyd）
//画像データ0にシェーディング補正フィルタをかける
FilterGaussUnshade(0,1,61,128,1,0,0,1)
//結果を格納するディレクトリを作成する
CreateDirectory( GetSrcFilePath(0) + "unshade" )
//表示画像をディレクトリに格納する
SaveViewAsBitmap(1, GetSrcFilePath(0) + "unshade\" + GetSrcFileName(0))

Doc/ScriptSpl「画像フィルタをかけてフォルダ作って保存.TXT」。サンプルは 9 本同梱されている。

字句

各位置で次の順に判定する（command_string_to_command_list）。行の前後には暗黙の括弧が付き、括弧の対応が検査される。

順種類規則
1文字列"…"。エスケープは無く、"\" は 1 文字の \
2コメント// 以降を捨てる
3数値[0-9]+(\.[0-9]*)?。指数表記・16 進・先頭の . は不可
4演算子2 文字 == <= >= != && || += -= *= /= を先に、次に 1 文字 + - * / < > =
5括弧( )
6マクロ名登録名と一致し、直後が (。大文字小文字を区別
7変数宣言済みの名前（最長一致）
8区切り, と ;（for(a;b;c) の ; もカンマ扱い）
9座標i・x は X 座標、j・y は Y 座標（同名の変数があれば変数が優先）

空白・タブは無視され、それ以外の文字はエラー（Error: line%d has invarid character）。

演算子と優先順位

構文木は作らず、トークンの連結リストを括弧単位で、優先順位の高いものから左結合で畳み込む（calculate_command_list）。

順処理備考
1マクロ呼び出しと入れ子の ( )再帰で値に置き換える
2変数・座標の値への置換代入演算子の左辺の変数は残す
3単項マイナス行頭・( の直後・代入の直後の - のみ（a*-1 は構文エラー）
4* /% 演算子は無い（剰余は mod()）
5+ -文字列同士の + は連結
6== < > <= >= !=結果は 1/0。文字列は == と != のみ
7&& ||同順位で左から評価。非 0 を真とする。短絡評価なし
8= += -= *= /=文字列は = と += のみ

!、べき乗演算子、ビット演算、三項演算子は無い。

画素参照

式意味
I(n)画像メモリ n の、現在評価中の画素 (x, y) の値
I(n, page)同、ページ指定
I(n, x, y) / I(n, x, y, page, ch)座標を指定して参照。サブピクセル座標は双一次補間、RGB 表示中は輝度
A(n, x, y, page, ch)座標指定の参照（5 引数のみ）
M(n)現在画素のマスク値
x(i), y(j)現在画素の座標。スクリプトウィンドウでは x=y=1 に固定

RGB 型でカラー表示のときは、チャネルごとに式を 3 回評価する。

制御構文

行の最初の語で判定する（大文字小文字を区別しない）。登録時に set_branch_property がネストを数えて対応行を探し、真偽それぞれの飛び先行番号を前計算する。対応が取れないと invarid IF/ENDIF block などのエラー。

構文動作
if(条件) … elseif(条件) … else … endif真のブロックだけを実行
while(条件) … endwhile条件が真の間繰り返す
for(初期化; 条件; 更新) … endfor初回は初期化→条件、2 回目以降は更新→条件。条件は数値であること
goto(n)行 n へ飛ぶ（0 ≦ n < 行数）
breakその行で実行を止める
clear変数と結果をすべて消し、先頭に戻って停止
var i, sum
sum = 0
for(i=0; i<10; i+=1)
  sum += i
endfor
ShowMessage(1, 1, "sum=" + ToString(sum, 0))
if(a>1) b=2 のように制御構文と同じ行に書いた文は、条件に関係なく実行される。ブロックは必ず改行して書く。また var を含む行は宣言行として扱われ、行中の他の記述は無視される。

評価器の構造

RegisterCommandString(行の配列, 行数)
  └ 行ごと（前回と同じ文字列ならキャッシュを再利用）
      FindVariableDefinission → FindCtrlCode → トークン化 → COMMAND 連結リスト
  └ set_branch_property（制御構文の飛び先を前計算）

Execute(行, x, y, …, apiMode, &次の行, batchIn, batchOut, autoDraw, blockMap)
  ├ 空行 → 次の行へ
  ├ clear → ClearAll、次は 0 行目、停止
  ├ リストを複製（評価でリストが壊れるため）
  ├ for → calculate_for_command_list ／ その他 → calculate_command_list
  │    └ マクロ → 引数を再帰評価 → 引数の数と型が一致する最初のオーバーロード → execute_macro
  ├ 結果と経過時間を記録
  └ 次の行番号を決める（制御構文は blockMap で状態管理）

ExecuteAPI(行, …) = Execute(行, 1, 1, …, apiMode=true)
  • トークンは COMMAND 構造体（prev/next、種類、数値、演算子、括弧、マクロ ID、文字列 ID、変数 ID）。種類は 0 数値、1 演算子、2 括弧、3 マクロ、4 カンマ、5 X、6 Y、7 文字列、8 制御、9 変数。
  • マクロの引数に暗黙の型変換は無く、合致しなければ Error: invarid argument for …。
  • マクロ ID が 100 以上のもの（画像操作などの API マクロ）は apiMode = true のときだけ実行される。数式ウィンドウは apiMode = false のため、そこで API マクロを書いても何もせず 0 を返す。

数式ウィンドウでの使い方

数式ウィンドウ（CCalcDlg）は 1 行の式を処理範囲の全画素について Execute(0, x, y) し、結果を画素値として書く（CPimpomAPI::CalcDataValue）。作業領域外・マスク画素は飛ばす。

式結果
2*I(0)+100画像 0 を 2 倍して 100 加算
(I(0)+I(1))/2画像 0 と 1 の平均
x/3X 座標の 1/3（グラデーション）
100*gaus()標準偏差 100 のガウスノイズ
thresh(I(0),128)*255128 を超える画素を 255 にする

スクリプトウィンドウ

機能仕様
連続実行10 ms タイマーで 1 tick ごとに 1 行ずつ実行。エラー・break・clear・末尾で停止
ステップ実行・ブレークポイント行番号欄のクリックでブレークポイントを切り替える。停止後は続きから実行できる
テスト実行1 行だけを別の評価器で実行（プログラムカウンタは動かさない）
結果表示各行の Res(n)=値 (経過[ms]) と、エラー欄（成功 "OK"、空行・コメント "---"）
変数ウォッチ宣言変数と BATCH_IN[0-4]、BATCH_OUT[0-14]
編集Undo 50 段。.txt を開く・保存・ドラッグ＆ドロップ
自動バックアップ終了時に script_backup.txt（exe フォルダ）へ保存し、次回起動時に読み込む
ヘルプサンプル（Doc\ScriptSpl）、スクリプトマニュアル、マクロ説明（Doc\macro_description.txt）を開く
バッチ連携ウィンドウ表示中は、バッチ実行の各件でスクリプト全体が先頭から同期実行される。GetBatchInput(i)／SetBatchOutput(i, v) でバッチの入出力パラメータを読み書きする

マクロ関数一覧

出典は CCalculate::define_macros()。引数の N は数値、S は文字列。画像処理系は src/dst に -1 を渡すと選択中の画像、multi は全ページ・チャネルに適用するかを表す。自動再描画が ON なら処理後に DrawImage(dst) される。戻り値の記載が無いものは成功時 0 を返す。

4. メイン画面とメニュー

メインウィンドウ（CPIMPOMDlg、リソース IDD_PIMPOM_DLG）の構成、メインメニュー全項目、マウス・キー操作を示す。ハンドラは WindowCtrlFiles/MainManuProc.cpp、メッセージマップは PIMPOMDlg.cpp。

画面構成

クライアント領域は「画像表示領域＋右 50px＋下 160px」。既定（画像 640×480）で 690×640。ウィンドウの右端・下端をドラッグしてリサイズすると画像表示領域が追従する（ini には保存しない）。

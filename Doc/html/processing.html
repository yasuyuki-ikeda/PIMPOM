6. 画像処理機能

汎用フィルタ、2 値化とラベリング、型変換、サイズ変換、幾何変換、数式による画像生成、画像間演算の仕様を示す。UI は各ダイアログ、処理本体は CPimpomAPI（API/）にある。

共通規則

項目規則
画像の指定src／dst に画像メモリ番号。-1（CURRENT_IMAGE）は選択中の画像（2 値化の dst など一部の関数は -1 不可）
処理範囲GetRectArea()。作業領域使用時は全図形の外接矩形（右・下端を含む）、未使用時は画像全体
ページ・チャネルtoMultiImage（UI の「全ページ/チャネルを対象」）が偽なら表示中の 1 平面だけ処理する
出力先src ≠ dst のときは src を dst にコピーしてから dst 上で処理する
値域出力値は型の上下限で飽和させる
パディングpad_type: 0 = ゼロ、1 = 外周画素の延長、2 = 折り返し
実装多くは自前のテンプレート実装（filter/template/*.h）で、BYTE・SHORT・WORD・LONG・DWORD・FLOAT の各型を扱う。一部は OpenCV を使う
Undoダイアログからの実行は処理前に BackupDataUnit で退避する
戻り値bool（成功／失敗）。失敗理由は返さない

2 値化とラベリング

CBinalizeDlg（モードレス）。原画像を 2 値化して結果画像に出力し、必要ならラベリングする。閾値スライダの操作や大津・P タイルの選択で即座に実行され、プレビューとして使える。

  • 結果は THREE_D 型（1 ページなら BYTE と同じ見え方）で、前景 255・背景 0。反転指定可。
  • RGB カラー表示中は輝度 (299R+587G+114B)/1000 で処理する。
  • 作業領域使用時は処理矩形の内部だけ処理する。
  • 結果先・ラベル先が原画像と同じ番号のときはエラー。実行前に結果先をバックアップする。
区分手法API内容パラメータ
グローバル閾値手入力Binalizemin ≦ v ≦ max の画素を前景にする閾値（0〜255、初期 128）
判別分析（大津法）BinalizeThresholdOtsu最小〜最大を 256 段階にし、クラス間／クラス内分散比が最大の閾値を求めて表示—
P タイル法BinalizeThresholdPTile累積度数が指定 % に達する閾値%（0〜100、初期 50）
ローカルガウシアン自己差分BinalizeLocalGaussI − Gauss(I) + offset ≧ 0 を前景。シェーディングを打ち消すサイズ 3〜61、offset −128〜128
ラプラシアンオブガウシアンBinalizeLocalLaplaceGaussLoG 応答 ≧ offset を前景。一定幅の線を強調同上
NICK 法BinalizeNick窓 (2w+1)² で T = m + k·√((ΣP² − m²)/NP)、P ≧ T を前景窓サイズ、k（−1〜0、初期 −0.03）

ラベリング

「ラベリングする」を ON にすると、2 値化結果に対して Label（cv::connectedComponentsWithStats、8 連結）を行い、ラベル画像を別の画像メモリ（既定は原画像＋2）に出力する。

  • 最小面積（初期 10）未満のラベルは数えない。ラベル数の上限は 9999。戻り値は最小面積以上のラベル数。
  • ラベル画像は FLOAT_3D 型の生ラベル番号で、パレットを「ラベル」（6 色循環）にして見分けやすくする。
  • 1 ページの場合は各ラベルの重心にマークを追加し、属性 0 に面積を入れる。
WORD 型の画像を 2 値化すると、閾値手入力・ローカル 2 手法・NICK で NULL ポインタを参照する不具合がある。P タイル法の閾値はデータのスケールに戻さず 0〜255 の段階番号で返る。

型変換

CConvertDataDlg（モーダル）。選択中の画像メモリの型を変換する（ConvertDataUnit、本体は CDataUnit::Convert）。

設定選択肢
変換元表示画像／データ／マスク／疑似カラー
変換元の成分RGB: 明度・彩度・色相・R・G・B ／ COMPLEX: 実部・虚部・パワー・位相 ／ XY・XYZ: 成分 ／ 3D 系: ページ
変換先の型表示画像 → BYTE（RGB 系は RGB）／データ → BYTE・RGB・SHORT・WORD・LONG・DWORD・FLOAT・XYZ・COMPLEX・3D・F3D ／マスク → BYTE ／疑似カラー → RGB
変換先の成分RGB: 全成分・R・G・B ／ COMPLEX: 実部・虚部 ／ 3D 系: ページ数・オフセット
上下限超過時飽和（初期 ON）／折り返し
  • 変換元は表示中のページ・チャネルで、RGB カラー表示中は輝度に変換してから移す。
  • 名前・作業領域・表示位置と倍率・マークは引き継ぐ。マスクはクリアされる。
  • XYZ への変換では Z にデータ、X = i − W/2、Y = −j + H/2 を入れる。
  • 変換オプションは構造体 CONVERT_DATA_OPTION（type_to、rgb_to、comp_to、satulate、byte_from、color_gray_method、threeD_page、threeD_offset）で渡す。
XY 型・RGB3D 型への変換は値が移らず 0 のまま（UI の候補からも外されている）。色相による灰色化は未実装。

サイズ変換

CResizeDataDlg（モーダル）。ResizeDataUnit を呼ぶ。実行後もダイアログは閉じない。

設定内容
格納先現在の画像に上書き／原画像 → 結果画像
幅・高さ変換後のサイズ（/2・×2 ボタンあり）
オフセット X・Y伸縮しないときの貼り付け位置
伸縮OFF: 拡大縮小せず、オフセット位置に貼る（はみ出しは切り捨て、余白は黒）。ON: 画像を新サイズに伸縮
縮小アルゴリズム面積平均／最大／最小

伸縮は x→y の分離処理で、拡大は双線形補間、縮小は面積積分。マスクも同様に変換され、表示コントラストの設定は保持される。

幾何変換（射影変換）

CTransformDlg（モーダル）。PerspectiveTransDataUnit（撮像条件版）を呼ぶ。XYZ 空間の XY 面に元画像が 1 pix = 1 mm で貼られていると想定し、仮想カメラで撮影したときの見え方に変換する。仮想カメラは視野が元画像の高さになり、光軸上に原点が来る位置に置く。

パラメータ初期値効果
焦点距離 f [mm]16大きいほど傾けたときの台形歪みが小さい
撮像素子サイズ a [μm]7.4大きいほど台形歪みが大きい
撮像素子ずれ TI, TJ [pix]0, 0画像の位置が変わる
回転 θ(Z), Ψ(Y), φ(X) [deg]0, 0, 0回転・台形変形
撮像面内移動 TX, TY [mm]0, 0画像の位置が変わる（TI, TJ と逆向き）
はみ出した画素を埋める—ON: 範囲外を端の画素で埋める／OFF: 書かない（黒）

内部では f[pix] = f[mm] / (a[μm]/1000·√2)、回転行列 R = R1(θ)·R2(φ)·R3(ψ) から射影行列 H を作り（SVD による逆行列）、逆写像

x = (p0·i + p1·j + p2) / D,  y = (p3·i + p4·j + p5) / D,  D = p6·i + p7·j + 1

を双線形補間で評価する。全ページ・チャネルが対象で、マスクも補間後に 2 値化して変換される。関連 API: PerspectiveTransDataUnit(p[8])（係数直接指定）、IsoTransDataUnit（平行移動・回転・倍率。内部では f=16 mm、7.4 μm の仮想カメラで射影変換を呼ぶ）、PerspectiveTransCoor（座標の変換）、ClipDataUnit（切り出し）。

XY 型に対するサイズ変換・射影変換・切り出しは出力ポインタが未初期化のまま使われる不具合がある。

数式による画像生成

CCalcDlg（数式ウィンドウ）。画素ごとの値を表す式を入力し、画像やマスクを生成する。式の文法は 7 章。

設定内容
数式コンボボックス。過去 10 件の履歴を pimpom.ini の [CALCLATION] に保存
上下限超過時飽和（ON）／折り返し（OFF）
格納先新規画像メモリ取得（幅・高さと型 BYTE／SHORT／WORD／LONG／DWORD／FLOAT／RGB を指定）／現在の画像に上書き（マスク・作業領域は保持）／演算結果からマスク生成
マスク生成の範囲演算結果が [min, max]（既定 0〜256）に入る画素を非マスク、外をマスク
マクロ一覧Doc\macro_help.txt を開く

実行時は (1,1) で試し評価して式を検査してから、処理矩形内の各画素（マスク画素・作業領域外は除く）について式を評価する。RGB を生成するときは R・G・B に同じ値が入る。実行前に格納先をバックアップする。

画像間演算

Calc2DataUnit（api_pixwise_calc.cpp）と、その別名関数で画像同士の演算を行う。dst は指定した型で作り直され、3 つとも RGB 系ならチャネルごとに計算する。作業領域とマスクは考慮しない。

関数計算
Linear2DataUnit(A, B, dst, type, wA, wB, bias, sat)A·wA + B·wB + bias
SumDataUnit / SubtractDataUnit / SubAbsDataUnitA+B ／ A−B ／ |A−B|
MultiplyDataUnit / DivideDataUnitA×B ／ A÷B（B=0 なら bias）
LinearDataUnit(n, dst, type, w, bias, sat)n·w + bias
AbsDataUnit|n|（スクリプトからは未実装で失敗する）
dst を src と同じ番号にすると、作り直しで入力が失われる。

9. API リファレンス概要

CPimpomAPI（include/PIMPOM_API.h）の関数を分類ごとにまとめる。公開メンバ関数の宣言は 286（オーバーロード込み）、関数名は 233 種類。個々の引数の詳細は PIMPOM_API.h と Doc/PIMPOM_APIリファレンス.docx を参照（同資料は改訂 1.5 時点で、現行と差異がある。付録）。

使い方と規約

  • グローバルオブジェクト API（PIMPOM_Core.cpp で定義）を通じて呼ぶ。カスタムファンクションでは雛形の #define API (*GetAPI()) を使う。
  • 画像番号に CURRENT_IMAGE（-1）を渡すと選択中の画像。ただし CopyDataUnit、2 値化・ラベリングの dst、DFT の dst、LoadIFZ などは -1 を受け付けない。
  • 多くの関数は bool を返し、失敗理由は返さない（CalcDataValue／CalcMaskValue のみエラー文字列を返す）。数値を返す関数（大津閾値、ハフ、ラベリング）は失敗時 0。
  • 一部の関数は確認ダイアログやメッセージボックスを出す（show 引数など）。無人実行では止まる原因になる。
  • 処理後に画面を更新するには API.DrawImage(n) を呼ぶ。
// 例: 画像 0 にガウシアンをかけて 1 に出力し、大津法で 2 値化して 2 に出力
API.FilterGauss(0, 1, 5, 0, 1, false);
double th = API.BinalizeThresholdOtsu(1);
API.Binalize(1, 2, th, 999999, false);
API.DrawImage(2);
API.ShowMessage(true, 1, false, "threshold = %f", th);

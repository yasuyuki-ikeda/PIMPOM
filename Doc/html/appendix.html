11. 付録

ソースファイル一覧、既存資料と現行コードの差異、コード解析で見つかった不具合の候補をまとめる。不具合の候補はソースの静的な読解によるもので、実行して確かめたものではない。

フォルダ構成

PIMPOM/
├─ PIMPOM2022.sln            … 本書の対象（PIMPOM2015.sln / PIMPOM2019.sln は旧版用）
├─ PIMPOM_EXE/               … PIMPOM.exe（起動のみ）
├─ PIMPOM_Core/              … 本体 DLL
│   ├─ API/                  … CPimpomAPI の実装
│   │   ├─ file_io/          … ファイル入出力
│   │   └─ filter/(template/)… フィルタ（型別テンプレート実装）
│   ├─ DataWrapper/          … CDataUnit・CWorkArea・CImageField・CCalculate・通信
│   ├─ WindowCtrlFiles/      … メイン画面と各ダイアログ
│   ├─ include/              … ヘッダ
│   └─ res/                  … アイコン・ビットマップ
├─ CustomFunc/UserDlgTemplate/ … カスタムファンクションの雛形
├─ Tool/CloneUserDlg/        … カスタムファンクション追加ツール
├─ Tool/PimpomPlotPy/        … Pimpom.pyd（Boost.Python）とコマンド抽出ツール
├─ external_data_transfer_sample/ … 外部連携サンプル
├─ python/                   … Pimpom.py
├─ OpenCV/                   … OpenCV 4.4.0
├─ bin/x64/{Debug,Release}/  … 実行フォルダ
└─ Doc/                      … 資料（本書は Doc/html）

不具合の候補

静的読解による候補。重大度は影響範囲からの目安。

重大度内容場所
高WORD 画像の 2 値化（閾値手入力・ローカル 2 手法・NICK）で NULL の pDwordData を参照するapi_binalize.cpp、api_binalize_nick.cpp
高XY 型のサイズ変換・射影変換・切り出しで出力ポインタが未初期化api_giometric_transform.cpp
高LONG／DWORD の cv::Mat 変換が未初期化ポインタを返すapi_support_opencv.cpp

高IMG_NUM に上限チェックが無く、1000 超で配列外を使うapi_func.cpp
